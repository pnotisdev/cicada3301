## Executive summary — one page

**The next frontier is model composition and calibration, not another seed list.** Existing negatives are useful conditional results, not exclusions of their key families under arbitrary pointer/emission rules. The M04 experiment establishes a consequential counterexample at its measured scope: the unchanged screen detected 14/100 hold-key plants, reached plaintext accuracy ≥.95 on 0/100, but detected 100/100 spend-key replacements; its held-out null flagged 2/100. This is not a reason to invalidate the skip/coin results themselves (`work/log/phase15_m04_baseline.md:19-49`).

**Three framework issues deserve priority; one is now partly corrected.**

- **H5 inherits an unjustified composition filter.** Its planned stream-plus-keyword search uses only streams passing the *plain additive* marginal-IoC filter. Adding a keyword changes that marginal law; a stream rejected alone need not be rejected in composition. The filter and the campaign are different models (`work/kscreen/export.py:265-283`; `work/keystreams.py:191-201`; `work/independent/frontier/evidence/h5_campaign_01b31fe.md:8-15`).
- **The gated-null failure is not a general impossibility theorem.** The later ungated prototype does not implement its declared local null prior: it omits the null-value probability and penalizes ordinary emission after a null. A different globally normalized mask prior can preserve its ratio, so this is **not** a proof that every use of that score is invalid. Its planted and decoded rate units also differ. Its report explicitly retains the wrong-plaintext-window caveat. These defects must be separated from the earlier deterministic value-gated implementation, and family detection must be separated from exact-offset identification (`work/tmp/gated_null_gate.py:78-80,264-290`; `work/tmp/gated_null_report.md:7-19,31-38,83-89`; `work/independent/echo_nulls.py:118-157`; `work/independent/frontier/LIKELIHOOD_NOTE.md`).
- **H5 calibration has been partly corrected concurrently.** The new review measured a campaign-size null for one window, found the old margin inadequate and revised the rule. Other windows still need matched nulls; the original smaller-bank objection is historical, not an untouched omission (`work/independent/frontier/evidence/h5_prelaunch_b38bc2e.txt:55-63`; `work/independent/frontier/evidence/h5_update_b38bc2e.md:18-36`).

**The strongest positive remains a restricted statistical lead, not a cipher identification.** T6's own-section-rate forecast is 79.298 hits against 80 observed; the selected-family retest reports p_MC=.001 at its simulation floor, and retrospective fixed halves give adjusted p=.008. These pay for specified local menus, not the entire discovery history, and do not identify collision causality or spend versus hold. The reference discriminator's power is only .260650 for one defined count experiment; actual-site power is unknown (`work/independent/collision_fixed_halves/README.md:8-14`; `work/log/collision_followup_2026-10-18.md:16-38`). No demonstrated model jointly explains the other echo, its source preference, lengths and trailer (`docs/registry.toml:870-872`).

**The ledger still overstates some conclusions.** F replacement is corrected to “disfavoured” in one field but remains “excluded” in another; the claimed broad lag-feedback scope is larger than the recorded extension; “independent OCR” uses transcription-trained labels. One local heading export has inconsistent lengths, and the local page-window file is empty. None of these facts, by itself, invalidates a historical run using different input hashes (`docs/registry.toml:475-478,666`; `work/tmp/lag_feedback_sweep_report.md:7-9`; `work/ocr.py:1-5`; `work/independent/frontier/AUDIT.md:24-31`).

**Recommended decision:** verify the actual prior and redefine the decoder gate; exhibit a planted H5 composition-filter counterexample; audit metadata/provenance; then attempt a simultaneous conditional feature test. Do not claim a predictive all-feature encryptor, an untouched replication, or a global historical p-value: all remain **unknown**. No engines or key searches were run for this review. The committed H5 update retains a failed true-offset plant and a replacement passing control, not universal power (`work/independent/frontier/evidence/h5_prelaunch_b38bc2e.txt:31-53`).

## C. One generative story — what can and cannot honestly be supplied

**E:** no reviewed package demonstrates a forward cipher jointly fitting all these features. The prior derivation says this explicitly (`work/independent/collision_substitution/DERIVATION.md:560-572`; `docs/registry.toml:872`). **I:** there is no proved incompatibility among the observations. The limited collision-budget calculation is not such a proof. **Unknown:** a parsimonious, lossless, historically plausible encryptor that quantitatively passes the complete joint check.

Here is **one** compositional forward model precise enough to expose the missing assumptions. It uses output-constrained coding rather than pretending that overwriting a plaintext symbol is automatically invertible. It is an existence-style construction, **not** a discovered Cicada algorithm, an implemented codec, or a passed predictive model.

```text
ENCRYPT(plaintext_words P, shared key K):
    # S: permute WORDS before the output cipher, not completed ciphertext after it.
    # This can erase natural length-order dependence while retaining the histogram.
    W = keyed_permutation(P, K.order)

    # E: a fitted length description, NOT measured insertions.
    # S: turn it into a literal, key-known length-changing layer.
    fitted_word_padding_rate = 0.42       # fitted description, not observed insertions
    for each word w in W:
        pad[w] = keyed_Bernoulli(K.pad, word_id, fitted_word_padding_rate)
                 if rune_length(w) > 1 else 0
    layout = [rune_length(w) + pad[w] for w in W]

    # S: a word-aware finite-history output law.
    # Start from the reference uniform-attempt/anti-doublet conditional law.
    Q = reference_collision_law(layout, q)
    # At eligible within-word sites, its repair destination may be T6(history).
    Q = add_T6_repair_destination(Q)
    # S: independent extra freedom is needed; NOT a second draw on the same budget.
    Q = tilt(Q, lag5_equality, lag5_source_S_preference)
    Q = normalize_each_history(Q)

    # S: a repeated two-word protocol marker, including one terminal occurrence.
    # Its letters are key-chosen, not selected because they spell DJU / BEI.
    marker = keyed_codeword_pair(K.marker)
    marker_constraints = {same_pair_at_two_slots, one_slot_terminal,
                          no_other_repeated_adjacent_word_pair}
    # Only layouts with compatible marker slots are admitted by this version.

    # E: measured feature vector; S: conditioning on it is deliberate overfitting.
    A = finite_typical_codebook(Q, layout, marker_constraints,
                                joint_doublet_I5_T6_source_and_offlag_feature_bands)
    # The bands include ordinary flat-marginal/other-lag diagnostics.
    # For a feature-existence witness, they can contain the observed vector.
    # For a scientific test, they must instead be fitted/frozen on training plants.

    # S: lossless enumerative/distribution-matching layer, not symbol overwriting.
    r, M = lossless_rank_of_message_given_layout(W)
    assert count(A) >= M                 # CAPACITY UNKNOWN; do not assume this passes.
    C = unrank_A((r + keyed_uniform_integer(K.code, count(A))) mod count(A))
    return C
```

The inverse ranks C in the same admissible set, subtracts the key integer, verifies membership in the message code, reconstructs W using the key-known padding/layout convention, and reverses the word permutation. Thus **if the capacity and framing checks pass**, no plaintext information has silently been discarded. Constructing that code or evaluating its capacity is **not** authorized or attempted here.

### How the components address the observations

- **Doublet suppression and T6 at a collision-sized rate:** the reference law supplies the starting relation, supported by the recorded T6 forecast. Extra tilts and marker conditioning change it; its final joint calibration is **unknown**, not still automatically the original forecast (`work/independent/collision_fixed_halves/README.md:13-14`).
- **Lag-5 and its S component:** a separate word-aware preference can create both. It is an additional fitted mechanism, not derived from T6, the alphabet labels or the coincidence of rates. The recorded source concentration alone does not supply its algorithm (`work/log/phase10_echo_values.md:17-24`).
- **Length excess and weak length-order dependence:** key-known padding implements the selected length description; pre-encryption word permutation can remove order without breaking subsequent output anti-repeat. Both are speculative, and the padding interpretation competes with spelling and corpus effects (`results/analysis/wordlen.txt:8`; `results/analysis/wordlen_adjacency.txt:3-16`; `docs/registry.toml:585-592`).
- **Flat statistics:** the base law is broadly mixing; the final admissible set can enforce the recorded marginal/off-lag bands. This is conditioning, **not a prediction**. Exact iid bigrams would conflict with the doublet deficit; “flat except the measured departures” does not.
- **Repeated terminal pair:** a protocol marker explains why ordinary keyless vocabulary statistics need not treat every pair as prose. Its existence, placement and literal value have not been predicted from an authenticated instruction (`docs/registry.toml:710`).

**Interpretation:** this construction shows how the features can coexist in one forward architecture; it does not furnish evidence for that architecture. Hard-conditioning on all discoveries is circular, capacity is unmeasured, and a finite uniform rank code need not follow Q exactly. This is a conditional construction, not an established existence proof at the required message capacity. Replacing this construction by a short predictive cipher, passing its lossless/planted controls, and reproducing the *joint* feature vector is the real unsolved task. I cannot honestly supply an already validated all-feature encryptor, and will not manufacture one by calling separately fitted rates “explained.”

The restrictive story that *does* have a demonstrated problem is “a homogeneous single collision budget explains every excess.” Its mean-budget/S-symmetry limitations are already calculated; stochastic fluctuations and alternate conditional laws prevent turning them into an incompatibility theorem for LP2 (`work/independent/collision_followup/PROTOCOL.md:192-239`; `work/independent/collision_substitution/DERIVATION.md:316-365`).
